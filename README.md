# Капибара: Апельсиновый остров

Мобильная браузерная игра. Играть: https://bertik3008.github.io/capybara/

На айфоне: открой ссылку в Safari → «Поделиться» → «На экран Домой». Появится иконка, игра запускается на весь экран и работает без интернета.

## Капик в космосе (3D)

3D-игра от первого лица: капибара Капик летает на дедушкиной тарелке между планетами и спасает четырёх братьев.
Играть: https://bertik3008.github.io/capybara/space/ (старые версии: https://bertik3008.github.io/capybara/space/v1.html , https://bertik3008.github.io/capybara/space/v2.html , https://bertik3008.github.io/capybara/space/v3.html , https://bertik3008.github.io/capybara/space/v4.html , https://bertik3008.github.io/capybara/space/v5.html , https://bertik3008.github.io/capybara/space/v7.html , https://bertik3008.github.io/capybara/space/v8.html и https://bertik3008.github.io/capybara/space/v9.html)

Исходники лежат в `space/src`, игра собирается в один файл командой `python3 space/build.py`.


Сборка для Яндекс Игр: `python3 space/build.py --yandex` -> `space/dist/kapik-yandex.zip` (всё внутри одного index.html, SDK подключается с платформы). Обложка, иконка, скриншоты, видео и тексты карточки лежат в `space/promo`.
