# Капибара: Апельсиновый остров

Мобильная браузерная игра. Играть: https://bertik3008.github.io/capybara/

На айфоне: открой ссылку в Safari → «Поделиться» → «На экран Домой». Появится иконка, игра запускается на весь экран и работает без интернета.

## Капик в космосе (3D)

3D-игра от первого лица: капибара Капик летает на дедушкиной тарелке между планетами и спасает четырёх братьев.
Играть: https://bertik3008.github.io/capybara/space/ (старые версии: https://bertik3008.github.io/capybara/space/v1.html , https://bertik3008.github.io/capybara/space/v2.html и https://bertik3008.github.io/capybara/space/v3.html)

Исходники лежат в `space/src`, игра собирается в один файл командой `python3 space/build.py`.
